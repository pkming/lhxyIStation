## 📊 文档说明

### 产品功能总览
**目标读者**：产品经理、项目经理、测试负责人  
**更新频率**：每个功能模块完成后更新  
**内容**：
- 系统简介与目标
- 核心功能列表
- 功能完成度矩阵
- 与M90对比说明

### 版本路线图
**目标读者**：项目管理者、产品经理  
**更新频率**：每次版本发布前更新  
**内容**：
- 当前版本状态
- 已完成功能清单
- 待真机验证项
- 下一版本计划
- 已知问题与暂缓项

### 平台对接协议说明
**目标读者**：测试人员、产品经理、运维人员  
**更新频率**：协议变更时更新  
**内容**：
- 平台下行消息（平台→终端）
- 终端上行消息（终端→平台）
- DVR串口调度链路
- 消息格式与示例

### 首页视频功能说明
**目标读者**：测试人员、产品经理  
**更新频率**：视频功能变更时更新  
**内容**：
- 视频状态机（5种状态）
- GPIO触发机制
- 防抖与优先级机制
- 测试场景与验证标准

## 🔄 文档维护规则

1. **新增功能**：功能完成后，先更新执行清单，再更新产品文档
2. **版本发布**：发布前必须更新版本路线图和产品功能总览
3. **协议变更**：协议修改后立即更新平台对接协议说明
4. **真机验证**：真机验证后更新对应功能的完成度状态
