## 一、系统简介

### 1.1 产品定位
Android11 车载终端系统是基于 Android 11 平台的新一代智能公交车载终端，对标现场版 M90 系统，实现完整的车载终端功能。

### 1.2 核心目标
- **100% 复刻 M90 功能**：页面、动作、状态、协议完全对齐
- **模块化架构**：保持代码可维护性和硬件可替换性
- **真机验证**：所有功能通过真机验证后闭合

### 1.3 技术架构
- **表现层**：Legacy 页面系列（对标 M90 UI）
- **业务层**：Business Module（模块化业务逻辑）
- **协议层**：Protocol Module（JT808、DVR、GPS 等）
- **设备层**：Device Adapter（GPIO、Camera、Serial、RFID）
- **配置层**：ShellConfig（运行时配置管理）

## 三、核心业务链路

### 3.1 平台对接链路 ✅ 100%

**完成状态**：10种下行 + 17种上行 + 9种DVR串口 = **100%对标完成**

#### 平台下行消息（10种）
- 0x8001 平台通用应答
- 0x8100 终端注册应答
- 0x8103 设置终端参数
- 0x8300 平台文本消息（司机/乘客区分、RS485转发）
- 0x8900 透传消息（参数）
- 0x8B01 平台调度计划
- 0x8B02 平台调度控制
- 0x8B05 车辆运营应答
- 0x8B09 职业请求应答
- 0x8B0A 平台升级下载命令

#### 终端上行消息（17种）
- 0x0001 终端通用应答
- 0x0002 终端心跳
- 0x0100 终端注册
- 0x0102 终端鉴权
- 0x0200 位置信息汇报
- 0x0107 查询终端属性应答
- 0x0900 业务请求（进出站/司机登录/职业请求）
- 0x0B02 报站信息
- 0x0B04 违规信息
- 0x0B05 司机考勤
- 0x0B06 校时应答
- 0x0B09 请求消息
- 0x0B0A 升级通知
- 0x0B0D 线路切换信息
- 0xDB0E AL808线路切换

#### DVR串口链路（9种）
- 0x5502 握手协议
- 0x5505 GPS数据转发
- 0x5506 站点信息发送
- 0x5510 调度应答
- 0x551E 下行消息应答
- 司机考勤同步
- 0x0F DVR调度下发
- 0x12 DVR公告下发
- 0x0E DVR考勤应答

### 3.2 首页视频链路 ✅ 100%

**完成状态**：**100%对标完成**

#### 视频状态机（5种）
1. **中门视频**：全屏中门摄像头
2. **倒车视频**：全屏倒车摄像头
3. **DVR视频**：小屏DVR摄像头
4. **倒车优先**：中门+倒车同时触发时倒车优先
5. **关闭视频**：无视频显示

#### GPIO触发机制
- **gpio1d1 + gpio1d0** 双引脚状态映射
- **350ms轮询周期**（对标M90）
- **50ms双重读取防抖**（对标M90）
- **独立GPIO监听线程**

#### 关键对标数值
| 参数 | M90 | Android11 | 状态 |
|------|-----|-----------|------|
| GPIO轮询周期 | 350ms | 350ms | ✅ 一致 |
| 防抖等待时间 | 50ms | 50ms | ✅ 一致 |
| 防抖读取次数 | 2次 | 2次 | ✅ 一致 |
| 响应延迟 | <400ms | <400ms | ✅ 一致 |
| 摄像头关闭策略 | 全部关闭 | 全部关闭 | ✅ 一致 |

## 五、与M90对比说明

### 5.1 架构差异

| 维度 | M90 | Android11 | 说明 |
|------|-----|-----------|------|
| **代码组织** | 业务集中在Activity/Fragment | 模块化分层（app/domain/protocol/device） | Android11保留模块化架构，功能语义复刻M90 |
| **配置管理** | SharedPreferences | ShellConfig统一配置层 | Android11配置更结构化，M90配置项完整对齐 |
| **设备访问** | 直接调用native | Adapter适配层 | Android11硬件可替换，M90设备语义完整对齐 |
| **页面结构** | 重Activity | Legacy页面系列 | Android11页面完全对标M90布局和控件 |

### 5.2 功能对齐度

**完全一致**（56项）：
- 登录页、菜单页、线路选择、基础设置7组
- 系统信息、信息浏览、密码设置、站点学习
- 平台协议36种、首页视频链路5种状态

**待真机验证**（15项）：
- 首页JHY客流、视频区GPIO、速度/限速真机观感
- 调度中心RFID刷卡、外设机务RS485
- 视频监控触摸字节序、四路cameraId
- GPS串口、自动报站、友情提醒、路口超速
- DVR预览、GPIO音频喇叭、资源包导入

**进行中**（1项）：
- GPS站点超速上报（资源字段受限）

### 5.3 不复刻项

以下M90历史功能不作为复刻目标：
- 旧4.4/K80文档口径与M90冲突的部分
- 调度动作页（M90正式宿主已移除）
- 语音通话页（M90菜单实际是密码设置）
- ModuleCenterActivity、BusinessModulesActivity（debug工具）

## 七、质量保证

### 7.1 对标验证标准
所有功能遵循"5本账"验证：
1. **页面账**：布局、控件、文案、显隐
2. **动作账**：按钮点击、跳转、回收
3. **状态账**：字段来源、刷新时机
4. **协议账**：发帧、收帧、状态写回
5. **验证账**：静态对照、点击回归、日志验证、真机验证

### 7.2 完成度判定口径
- **100% 已闭合**：页面/动作/状态/协议/验证5账全部满足，无待确认项
- **90% 待真机验证**：代码逻辑已按M90收口，需真机硬件/协议/资源证据
- **80% 部分待验证**：主链已接通，有明确资源/硬件限制
- **<80%**：有明确代码或数据源缺口

### 7.3 不算缺口项
- 结构不逐行复刻M90（Android11保留模块化架构）
- debug工具页面不复刻
- 旧4.4文档与M90冲突时不采纳旧4.4
- M90已移除的历史功能不恢复
