# Android11 车载终端系统 - 平台对接协议说明

**文档版本**：v1.0  
**最后更新**：2026-08-14  
**对标基准**：现场版 M90 V32  
**协议标准**：JT/T 808-2013 + 厂商扩展

---

## 一、协议概述

### 1.1 协议体系
Android11 车载终端与调度平台之间采用基于 JT/T 808-2013 标准的私有协议，包含平台下行消息、终端上行消息、DVR串口调度链路三部分。

### 1.2 完成状态
- **平台下行消息**：10种 ✅ 100%完成
- **终端上行消息**：17种 ✅ 100%完成
- **DVR串口链路**：9种 ✅ 100%完成
- **整体完成度**：✅ **100%对标完成**

## 二、平台下行消息（平台 → 终端）

### 2.1 0x8001 - 平台通用应答
**功能**：平台对终端上行消息的通用应答  
**完成度**：✅ 100%

**消息体结构**：
```
应答流水号：WORD（2字节）
应答ID：WORD（2字节）
结果：BYTE（1字节）
  0 = 成功/确认
  1 = 失败
  2 = 消息有误
  3 = 不支持
```

**实现位置**：`DispatchBusinessModule.handlePlatformGeneralResponse()`

---

### 2.2 0x8100 - 终端注册应答
**功能**：平台对终端注册请求的应答，包含鉴权码  
**完成度**：✅ 100%

**消息体结构**：
```
应答流水号：WORD（2字节）
结果：BYTE（1字节）
  0 = 成功
  1 = 车辆已被注册
  2 = 数据库中无该车辆
  3 = 终端已被注册
  4 = 数据库中无该终端
鉴权码：STRING（注册成功后填充）
```

**关键逻辑**：
- 注册成功后保存鉴权码
- 自动触发0x0102鉴权请求

**实现位置**：`DispatchBusinessModule.handleRegistrationResponse()`

---

### 2.3 0x8103 - 设置终端参数
**功能**：平台下发终端参数配置  
**完成度**：✅ 100%

**消息体结构**：
```
参数总数：BYTE（1字节）
参数项列表：
  参数ID：DWORD（4字节）
  参数长度：BYTE（1字节）
  参数值：BYTE[N]
```

**支持的参数**（通过0x8900透传）：
| 参数ID | 参数名称 | 单位 | 说明 |
|--------|---------|------|------|
| type=12 | 心跳间隔 | 秒 | 终端心跳发送间隔 |
| type=13 | GPS上报间隔 | 秒 | 位置信息上报间隔 |
| type=14 | 超速上报间隔 | 秒 | 超速信息上报间隔 |
| type=15 | 超速阈值 | km/h | 超速判定速度 |
| type=21 | TTS音量 | 0-15 | 语音播报音量 |

**实现位置**：`DispatchBusinessModule.handleSetTerminalParameters()`

---

### 2.4 0x8300 - 平台文本消息 ⭐ 核心
**功能**：平台下发文本消息，支持司机/乘客区分、TTS播报、RS485转发  
**完成度**：✅ 100%

**消息体结构**：
```
标志：BYTE（1字节）
  bit0: 紧急标志
  bit1: 保留
  bit2: 终端显示
  bit3: TTS播报
  bit4: 司机端（扩展）
  bit5: 乘客端（扩展）
  bit6-7: 保留
文本信息：STRING
```

**关键逻辑**：
1. **司机端消息**（flag.bit4=1）：
   - TTS从小喇叭播放
   - 首页显示消息
   - 不转发RS485

2. **乘客端消息**（flag.bit5=1）：
   - TTS从内音播放
   - 通过RS485转发给第三方设备
   - 首页显示消息

3. **消息存储**：
   - 存入MessageModel数据库
   - 支持历史消息查看
   - 标记已读/未读状态

**实现位置**：
- `DispatchBusinessModule.handlePlatformTextMessage()`
- `LegacyStationAudioUseCase.playDispatchNotice()` - 音频路由
- `PlatformMessageRepository` - 数据库存储

---

## 五、协议配置说明

### 5.1 网络配置
**配置位置**：基础设置 → 网络设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 调度ID | 终端唯一标识 | 从配置读取 |
| 协议类型 | JT808/AL808/ALINK | JT808 |
| 服务器IP | 调度平台IP地址 | - |
| 服务器端口 | 调度平台端口 | 8888 |
| 心跳间隔 | 终端心跳间隔（秒） | 30 |
| 信息间隔 | GPS上报间隔（秒） | 60 |
| 超速间隔 | 超速上报间隔（秒） | 30 |
| 更新服务器 | 文件更新服务器地址 | - |

### 5.3 调度归属配置

**可选值**：

## 七、故障排查

### 7.1 平台连接失败
**现象**：系统信息显示"未连接"

**排查步骤**：
1. 检查网络配置：IP、端口是否正确
2. 检查网络连接：ping服务器IP
3. 检查防火墙：端口是否开放
4. 查看日志：`SOCKET_CONNECT_FAILED`

---

### 7.2 心跳超时
**现象**：系统信息显示"已连接"，但频繁断开

**排查步骤**：
1. 检查心跳间隔配置
2. 查看日志：`HEARTBEAT_SENT`、`HEARTBEAT_TIMEOUT`
3. 检查平台是否正常响应0x8001

---

### 7.3 文本消息不播报
**现象**：收到0x8300消息，但无TTS播报

**排查步骤**：
1. 检查消息flag.bit3是否为1
2. 检查TTS设置是否开启
3. 检查调度音量配置
4. 查看日志：`DISPATCH_TEXT_MESSAGE`、`TTS_PLAY`

---

### 7.4 DVR串口无数据
**现象**：配置DVR协议后，串口无发送

**排查步骤**：
1. 检查调度归属是否为`serial_rs232_1`
2. 检查RS232-1协议是否为`DVR`
3. 检查RS232-1波特率（默认115200）
4. 查看日志：`DVR_SEND_*`
5. 使用串口监视器抓包
